This post explains how to use AWS Transform custom, an AI service for code modernization, to upgrade Lambda function runtimes across multiple functions. It addresses both application teams and platform teams, covering documentation analysis, validation planning, code transformation, and deployment validation, including automating upgrades like converting Node.js callback-based handlers to async/await patterns.
